# Матеріали Лабораторної роботи № 3

### Архітектурний стиль та діаграма
Для системи управління стоматологічною клінікою було обрано та обґрунтовано 3-рівневу клієнт-серверну архітектуру (React, Node.js, PostgreSQL/MongoDB). Архітектурна діаграма відображає взаємодію клієнтського фронтенду, серверного REST API та баз даних із дотриманням вимог безпеки та високої продуктивності.

### ER-діаграма бази даних
Спроєктована ER-діаграма у нотації Баркера визначає логічну структуру з 11 сутностей для збереження даних користувачів, прийомів, лікарень та чеків. Модель враховує специфіку роботи із чутливими даними через шифрування, підтримує ізольовані сутності (наприклад, OTP-коди) та запевняє цілісність зв'язків.

### Каркас (Wireframe)
Низькодеталізований каркас розроблено для 7 основних екранів застосунку у чорно-білій стилістиці. Він визначає базову компоновку елементів, сітку, розташування кнопок без прив'язки до візуального оформлення.

### Макет (Mockup)
Фінальний High-Fidelity макет реалізовано у стилістиці Material Design 3 із застосуванням м'якого пастельного фону контейнерів та яскравих акцентних елементів. На макеті проілюстровано повний сценарій взаємодії користувача (User Flow) із відображенням шляхів переходу між усіма 7 екранами.
